# LimerickGen

Generate proper AABBA limericks from any name or topic. True rhyme banks, one-tap generation, and a favourites shelf. Free.

## Features
- AABBA generator with true-rhyme word banks from any name or topic
- Rhyme bank browser for hand-editing poems
- Favourites shelf to save your best limericks
